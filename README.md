# 智能家居设备控制模拟系统

面向对象程序设计课程的连续上机项目，使用 C++ 和 Code::Blocks 开发。

## 当前进度

### Lab01 - 智能设备基本类

- 定义 `Device` 类，保存设备编号、名称、房间和开关状态。
- 支持创建设备，并校验空编号、重复编号和空名称。
- 支持显示全部设备以及按编号查询设备。
- 支持按编号开启、关闭设备，并提示重复控制。
- 提供循环菜单和非法输入处理。

## 运行方式

1. 使用 Code::Blocks 打开 `SmartHomeLab01.cbp`。
2. 选择 Debug 或 Release 目标。
3. 点击 Build and Run，或按 `F9`。
